# PDF OCR (구글 Vision)

스캔한 PDF를 **검색·드래그·복사가 되는 PDF**로 만들어 주는 윈도우 프로그램입니다.
구글 Cloud Vision으로 글자를 인식하고, 원본 모양은 그대로 둔 채 보이지 않는 글자 레이어를 입힙니다.

- 한글 인식률이 높고, ①②③ / ㉠㉡㉢ 같은 작은 기호도 잘 읽습니다. 페이지를 300dpi로 읽기 때문입니다.
- 비뚤게 스캔된 페이지를 똑바로 세워 줍니다(기울기 보정). OCR 결과로 각도를 계산하므로 추가 요금이 없습니다.
- 원하는 페이지에서 PDF를 나눌 수 있습니다. 예: 문제 / 정답과 해설
- 인식한 글자를 텍스트 파일(.txt)로도 저장할 수 있습니다.
- 중간에 멈춰도 이어서 할 수 있고, 같은 페이지에 요금이 두 번 나가지 않습니다.
- 구글 클라우드 설정(결제 연결, API 켜기, API 키 발급)을 스크립트 한 번으로 끝낼 수 있습니다.

## 다운로드

[Releases](https://github.com/supergangy/pdf-ocr-korean/releases)에서 `PDF_OCR.exe`를 받아 실행하세요. 설치나 파이썬은 필요 없습니다.

> 처음 실행할 때 윈도우 "PC 보호" 경고가 뜨면 **추가 정보 → 실행**을 누르세요.
> 서명되지 않은 개인 프로그램이라 뜨는 경고입니다. 소스 코드는 이 저장소에서 모두 확인할 수 있습니다.

## 사용 방법

### 1. 처음 한 번만: 구글 클라우드 준비 (약 5분)

1. [구글 클라우드](https://cloud.google.com/free)에 가입하고 결제 계정을 만듭니다(카드 등록). 신규 가입하면 300달러 크레딧을 줍니다.
2. 프로그램의 **처음 설정 / 사용법** 탭에서 **Cloud Shell 열기**를 누릅니다.
3. **설정 스크립트 복사**를 누르고, Cloud Shell에 붙여넣은 뒤 Enter를 누릅니다.
   - 스크립트가 프로젝트 선택, 결제 연결, Vision API 켜기, API 키 발급을 자동으로 합니다. 스크립트 내용은 [setup_google_cloud.sh](setup_google_cloud.sh)와 같습니다.
4. 마지막에 나온 `AIza...` 키를 프로그램의 **API 키** 칸에 붙여넣고 **연결 테스트**를 누릅니다.

### 2. OCR 하기

1. **추가**로 PDF를 고릅니다. 여러 개를 고를 수 있습니다.
2. 필요하면 옵션을 정합니다. 페이지 범위, 분할 시작 페이지, 텍스트 파일 저장 등이 있습니다.
3. **OCR 시작**을 누르면 페이지 수와 예상 요금이 나옵니다. 확인하고 **예**를 누릅니다.
4. 결과는 원본 PDF와 같은 폴더에 `원본이름(OCR).pdf`로 저장됩니다.

## 요금

구글 Cloud Vision은 **매달 1,000페이지까지 무료**입니다. 넘으면 1,000페이지당 약 1.5달러가 나옵니다([요금 안내](https://cloud.google.com/vision/pricing)).
요금은 구글 클라우드 계정으로 청구되며, 이 프로그램은 요금과 관계가 없습니다.

## 소스에서 실행 / 빌드

```bash
pip install -r requirements.txt
python ocr_app.py        # 실행
build.bat                # dist\PDF_OCR.exe 만들기
```

## 주의

- API 키와 인증키(json)는 다른 사람에게 공유하지 마세요. 프로그램은 키를 사용자 폴더의 `.pdf_ocr_app.json`에만 저장합니다.
- 책 같은 저작물을 OCR한 결과물은 개인적으로만 사용하세요. 다른 사람에게 배포하면 저작권 침해가 될 수 있습니다.
- 이 프로그램은 구글의 공식 프로그램이 아닙니다.
